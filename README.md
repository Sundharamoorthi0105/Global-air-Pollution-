# 🌍 Global Air Pollution Dashboard

## 📌 Project Overview
The **Global Air Pollution Dashboard** is an interactive data visualization project developed to analyze and monitor air pollution levels across different countries and cities. The dashboard provides insights into major air quality indicators such as AQI, CO, NO2, Ozone, and PM2.5 levels.

This project helps users understand pollution patterns, compare countries, and identify regions with high pollution levels through interactive charts and filters.

---

# 📊 Dashboard Features

- Average AQI Analysis
- CO AQI Monitoring
- NO2 AQI Analysis
- Ozone AQI Analysis
- PM2.5 AQI Analysis
- Top 5 Countries by Average AQI
- Country-wise Pollution Comparison
- AQI Category Distribution
- Interactive Filters (City & Country)

---

# 📈 KPIs Included

- Avg of AQI Values
- Avg of CO AQI Values
- Avg of NO2 AQI Values
- Avg of Ozone AQI Values
- Avg of PM2.5 AQI Values

# 🎯 Project Objectives

- Identify unhealthy regions
- Provide interactive filtering options

# 🚀 How to Use

1. Download the dataset
2. Open the `.pbix` file in Power BI
3. Use slicers to filter:
   - City
   - Country
4. Analyze KPIs and charts
5. Compare pollution levels across countries

# 📌 Key Insights

- Some countries show significantly higher AQI values.
- PM2.5 contributes heavily to unhealthy air conditions.
- Ozone and NO2 levels vary across cities.
- Interactive filters help identify pollution hotspots quickly.
